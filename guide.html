🎨 1. Color Picker

The Color Picker is our flagship tool. It lets you explore any color in detail — see its hex, RGB, HSL, and CMYK values, plus a full palette of related colors.

How to use it:

  1. Click the color wheel or type a hex code (like #6366F1) in the input box.
  2. Use the sliders to fine-tune hue, saturation, and lightness.
  3. Scroll down to see automatically generated harmonies: complementary, analogous, triadic, and more.
  4. Click any color value to copy it to your clipboard.
  5. Use the shade/tint palette to find lighter or darker versions of the same color.
💡 Pro tip: Click the eyedropper icon (in supported browsers) to pick a color from anywhere on your screen — even from outside the browser window.

🔄 2. Color Converter

Convert between 8 different color formats instantly: HEX, RGB, HSL, CMYK, HSV, HWB, LAB, and XYZ.

How to use it:

  1. Enter a color value in any of the input fields — it doesn't matter which one.
  2. All other formats update automatically as you type.

Create beautiful CSS gradients in seconds. Supports linear, radial, and conic gradients with up to 5 color stops.

How to use it:

  2. Add or remove color stops using the + and – buttons (2-5 stops supported).
  3. Click each color stop to change its color and position.

👁️ 4. Contrast Checker

Check if your text and background colors meet WCAG accessibility standards. Essential for making sure your website is usable by everyone.

How to use it:

  1. Enter a text color and a background color (or click to use the color picker).
  2. Instantly see the contrast ratio and pass/fail status for WCAG AA and AAA standards.
  3. Use the live preview to see how sample text looks with your color pair.
  4. Try the "auto-adjust" feature — we'll nudge the colors slightly to make them pass while staying as close as possible to your original.

WCAG standards at a glance:

  • AA Normal: 4.5:1 minimum contrast for body text
  • AA Large: 3:1 minimum for large text (18pt+ or 14pt bold+)
  • AAA Normal: 7:1 minimum for enhanced accessibility
  • AAA Large: 4.5:1 minimum for large text
💡 Pro tip: Contrast requirements are lower for large text because larger text is inherently easier to read. Text counts as "large" at 18pt (24px) or above, or 14pt (18.66px) bold or above.

⌨️ 9. Tips & Shortcuts

All HexColor Pro tools support these common shortcuts and features:

  • Click to copy: Click any hex, RGB, or HSL value to copy it to your clipboard.
  • Color input: You can paste any valid CSS color — hex, rgb(), hsl(), or even color names.
  • # is optional: When typing a hex code, you can skip the # symbol.
  • 3-digit hex: Short hex codes like #f00 work everywhere.
  • Dark mode: The site follows your system's dark mode preference automatically.

❓ Frequently Asked Questions

Is HexColor Pro free to use?

Yes! All tools on HexColor Pro are completely free to use. There's no sign-up required and no hidden fees.

Do I need to install anything?

No. HexColor Pro runs entirely in your web browser. Just visit the site and start using the tools — no downloads, no plugins, no account needed.

Does HexColor Pro work offline?

Most of our tools work even if your internet connection drops, since all the color calculations happen in your browser. Just bookmark the page and you're good to go.

Are the colors accurate?

All color conversions use standard math formulas (sRGB color space). Your display will affect how colors look, but the values are mathematically correct.

Can I suggest a new tool?

Absolutely! We're always adding new tools. Use the contact page to send us your suggestions.

What browsers are supported?

All modern browsers: Chrome, Firefox, Safari, Edge, and Brave. Some advanced features (like the eyedropper tool) may only work in Chromium-based browsers.
