Color Formats Explained

🎨 HEX

The most common web color format. Uses 6 hexadecimal digits (00-FF) for red, green, and blue. Example: #FF5733. Used everywhere in web development — CSS, HTML, design tools.

🔴 RGB

Red, Green, Blue — each from 0-255. Direct representation of how screens emit light. Example: rgb(255, 87, 51). The standard for digital displays.

🌀 HSL

Hue (0-360°), Saturation (%), Lightness (%). More intuitive for humans — "pick a hue, make it more/less saturated, lighter/darker." Great for creating color variations programmatically.

💎 HSV

Hue, Saturation, Value (brightness). Similar to HSL but "value" goes from black to full color, while HSL lightness goes from black to white. Common in design software.

🖨️ CMYK

Cyan, Magenta, Yellow, Key (black). The print standard — based on ink absorption rather than light emission. Convert to CMYK when designing for print.

💡 When to Use Which?

  • Web / CSS → HEX or HSL (HEX for precision, HSL for easy tweaking)
  • UI Design → HSL (easy to create consistent color systems)
  • Print Design → CMYK (ensures accurate print output)
  • Image Editing → RGB or HSV (full digital color range)
