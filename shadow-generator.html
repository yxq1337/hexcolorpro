Understanding CSS Box Shadow

📐 The Syntax

box-shadow: offset-x offset-y blur spread color inset;

  • offset-x — Horizontal distance (positive = right, negative = left)
  • offset-y — Vertical distance (positive = down, negative = up)
  • blur — Softness of the shadow edge (0 = hard edge)
  • spread — Size increase/decrease of the shadow
  • color — Shadow color (use rgba for transparency)
  • inset — Optional keyword for inner shadows

🎯 Design Tips

  • Use low opacity (10-30%) for natural-looking shadows
  • Pair multiple shadows for realism: a soft one + a harder one
  • Match shadow direction to your light source for consistency
  • Lighter, larger shadows feel more "floating"; tight dark shadows feel "pressed"
  • For dark mode, use colored shadows (match the element's hue) instead of black

✨ Multiple Shadows

You can layer multiple shadows by comma-separating them. This creates more depth than a single shadow:

box-shadow: 0 1px 2px rgba(0,0,0,0.05), 0 10px 20px rgba(0,0,0,0.1), 0 20px 40px rgba(0,0,0,0.15);
