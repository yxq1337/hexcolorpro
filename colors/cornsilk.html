#FFF8DC — Cornsilk

Cornsilk is the CSS named color #FFF8DC — rgb(255, 248, 220), hsl(48, 100%, 93%). Its relative luminance is 0.936, giving 1.07:1 against white and 19.71:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for cornsilk?

cornsilk is #FFF8DC, which is rgb(255, 248, 220) and hsl(48, 100%, 93%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is cornsilk light or dark?

Cornsilk has a relative luminance of 0.936 on a 0–1 scale, so it is a light color. Against white it scores 1.07:1; against black, 19.71:1.

Can I use cornsilk for text?

cornsilk reaches 19.71:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
