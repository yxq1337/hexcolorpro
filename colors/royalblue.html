#4169E1 — Royal Blue

Royal Blue is the CSS named color #4169E1 — rgb(65, 105, 225), hsl(225, 73%, 57%). Its relative luminance is 0.167, giving 4.85:1 against white and 4.33:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for royalblue?

royalblue is #4169E1, which is rgb(65, 105, 225) and hsl(225, 73%, 57%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is royalblue light or dark?

Royal Blue has a relative luminance of 0.167 on a 0–1 scale, so it is a dark color. Against white it scores 4.85:1; against black, 4.33:1.

Can I use royalblue for text?

royalblue reaches 4.85:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
