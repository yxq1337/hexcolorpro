#FFE4C4 — Bisque

Bisque is the CSS named color #FFE4C4 — rgb(255, 228, 196), hsl(33, 100%, 88%). Its relative luminance is 0.807, giving 1.22:1 against white and 17.15:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for bisque?

bisque is #FFE4C4, which is rgb(255, 228, 196) and hsl(33, 100%, 88%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is bisque light or dark?

Bisque has a relative luminance of 0.807 on a 0–1 scale, so it is a light color. Against white it scores 1.22:1; against black, 17.15:1.

Can I use bisque for text?

bisque reaches 17.15:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
