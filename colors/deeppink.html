#FF1493 — Deep Pink

Deep Pink is the CSS named color #FF1493 — rgb(255, 20, 147), hsl(328, 100%, 54%). Its relative luminance is 0.239, giving 3.64:1 against white and 5.77:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for deeppink?

deeppink is #FF1493, which is rgb(255, 20, 147) and hsl(328, 100%, 54%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is deeppink light or dark?

Deep Pink has a relative luminance of 0.239 on a 0–1 scale, so it is a dark color. Against white it scores 3.64:1; against black, 5.77:1.

Can I use deeppink for text?

deeppink reaches 5.77:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
