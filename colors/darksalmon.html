#E9967A — Dark Salmon

Dark Salmon is the CSS named color #E9967A — rgb(233, 150, 122), hsl(15, 72%, 70%). Its relative luminance is 0.405, giving 2.31:1 against white and 9.11:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for darksalmon?

darksalmon is #E9967A, which is rgb(233, 150, 122) and hsl(15, 72%, 70%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is darksalmon light or dark?

Dark Salmon has a relative luminance of 0.405 on a 0–1 scale, so it is a dark color. Against white it scores 2.31:1; against black, 9.11:1.

Can I use darksalmon for text?

darksalmon reaches 9.11:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
