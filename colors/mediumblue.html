#0000CD — Medium Blue

Medium Blue is the CSS named color #0000CD — rgb(0, 0, 205), hsl(240, 100%, 40%). Its relative luminance is 0.044, giving 11.16:1 against white and 1.88:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for mediumblue?

mediumblue is #0000CD, which is rgb(0, 0, 205) and hsl(240, 100%, 40%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is mediumblue light or dark?

Medium Blue has a relative luminance of 0.044 on a 0–1 scale, so it is a dark color. Against white it scores 11.16:1; against black, 1.88:1.

Can I use mediumblue for text?

mediumblue reaches 11.16:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
