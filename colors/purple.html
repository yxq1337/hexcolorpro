#800080 — Purple

Purple is the CSS named color #800080 — rgb(128, 0, 128), hsl(300, 100%, 25%). Its relative luminance is 0.061, giving 9.42:1 against white and 2.23:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for purple?

purple is #800080, which is rgb(128, 0, 128) and hsl(300, 100%, 25%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is purple light or dark?

Purple has a relative luminance of 0.061 on a 0–1 scale, so it is a dark color. Against white it scores 9.42:1; against black, 2.23:1.

Can I use purple for text?

purple reaches 9.42:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
