#DC143C — Crimson

Crimson is the CSS named color #DC143C — rgb(220, 20, 60), hsl(348, 83%, 47%). Its relative luminance is 0.160, giving 4.99:1 against white and 4.21:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for crimson?

crimson is #DC143C, which is rgb(220, 20, 60) and hsl(348, 83%, 47%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is crimson light or dark?

Crimson has a relative luminance of 0.160 on a 0–1 scale, so it is a dark color. Against white it scores 4.99:1; against black, 4.21:1.

Can I use crimson for text?

crimson reaches 4.99:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
