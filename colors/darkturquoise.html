#00CED1 — Dark Turquoise

Dark Turquoise is the CSS named color #00CED1 — rgb(0, 206, 209), hsl(181, 100%, 41%). Its relative luminance is 0.487, giving 1.95:1 against white and 10.75:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for darkturquoise?

darkturquoise is #00CED1, which is rgb(0, 206, 209) and hsl(181, 100%, 41%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is darkturquoise light or dark?

Dark Turquoise has a relative luminance of 0.487 on a 0–1 scale, so it is a dark color. Against white it scores 1.95:1; against black, 10.75:1.

Can I use darkturquoise for text?

darkturquoise reaches 10.75:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
