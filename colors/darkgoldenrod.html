#B8860B — Dark Goldenrod

Dark Goldenrod is the CSS named color #B8860B — rgb(184, 134, 11), hsl(43, 89%, 38%). Its relative luminance is 0.273, giving 3.25:1 against white and 6.45:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for darkgoldenrod?

darkgoldenrod is #B8860B, which is rgb(184, 134, 11) and hsl(43, 89%, 38%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is darkgoldenrod light or dark?

Dark Goldenrod has a relative luminance of 0.273 on a 0–1 scale, so it is a dark color. Against white it scores 3.25:1; against black, 6.45:1.

Can I use darkgoldenrod for text?

darkgoldenrod reaches 6.45:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
