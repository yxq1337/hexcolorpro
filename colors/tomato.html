#FF6347 — Tomato

Tomato is the CSS named color #FF6347 — rgb(255, 99, 71), hsl(9, 100%, 64%). Its relative luminance is 0.306, giving 2.95:1 against white and 7.13:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for tomato?

tomato is #FF6347, which is rgb(255, 99, 71) and hsl(9, 100%, 64%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is tomato light or dark?

Tomato has a relative luminance of 0.306 on a 0–1 scale, so it is a dark color. Against white it scores 2.95:1; against black, 7.13:1.

Can I use tomato for text?

tomato reaches 7.13:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
