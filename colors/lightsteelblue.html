#B0C4DE — Light Steel Blue

Light Steel Blue is the CSS named color #B0C4DE — rgb(176, 196, 222), hsl(214, 41%, 78%). Its relative luminance is 0.540, giving 1.78:1 against white and 11.80:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for lightsteelblue?

lightsteelblue is #B0C4DE, which is rgb(176, 196, 222) and hsl(214, 41%, 78%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is lightsteelblue light or dark?

Light Steel Blue has a relative luminance of 0.540 on a 0–1 scale, so it is a light color. Against white it scores 1.78:1; against black, 11.80:1.

Can I use lightsteelblue for text?
