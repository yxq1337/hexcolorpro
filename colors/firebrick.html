#B22222 — Firebrick

Firebrick is the CSS named color #B22222 — rgb(178, 34, 34), hsl(0, 68%, 42%). Its relative luminance is 0.107, giving 6.68:1 against white and 3.14:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for firebrick?

firebrick is #B22222, which is rgb(178, 34, 34) and hsl(0, 68%, 42%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is firebrick light or dark?

Firebrick has a relative luminance of 0.107 on a 0–1 scale, so it is a dark color. Against white it scores 6.68:1; against black, 3.14:1.

Can I use firebrick for text?

firebrick reaches 6.68:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
