#00FF00 — Lime

Lime is the CSS named color #00FF00 — rgb(0, 255, 0), hsl(120, 100%, 50%). Its relative luminance is 0.715, giving 1.37:1 against white and 15.30:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for lime?

lime is #00FF00, which is rgb(0, 255, 0) and hsl(120, 100%, 50%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is lime light or dark?

Lime has a relative luminance of 0.715 on a 0–1 scale, so it is a light color. Against white it scores 1.37:1; against black, 15.30:1.

Can I use lime for text?

lime reaches 15.30:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
