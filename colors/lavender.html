#E6E6FA — Lavender

Lavender is the CSS named color #E6E6FA — rgb(230, 230, 250), hsl(240, 67%, 94%). Its relative luminance is 0.803, giving 1.23:1 against white and 17.06:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for lavender?

lavender is #E6E6FA, which is rgb(230, 230, 250) and hsl(240, 67%, 94%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is lavender light or dark?

Lavender has a relative luminance of 0.803 on a 0–1 scale, so it is a light color. Against white it scores 1.23:1; against black, 17.06:1.

Can I use lavender for text?

lavender reaches 17.06:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
