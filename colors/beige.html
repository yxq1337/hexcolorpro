#F5F5DC — Beige

Beige is the CSS named color #F5F5DC — rgb(245, 245, 220), hsl(60, 56%, 91%). Its relative luminance is 0.899, giving 1.11:1 against white and 18.98:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for beige?

beige is #F5F5DC, which is rgb(245, 245, 220) and hsl(60, 56%, 91%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is beige light or dark?

Beige has a relative luminance of 0.899 on a 0–1 scale, so it is a light color. Against white it scores 1.11:1; against black, 18.98:1.

Can I use beige for text?

beige reaches 18.98:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
