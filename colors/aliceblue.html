#F0F8FF — Alice Blue

Alice Blue is the CSS named color #F0F8FF — rgb(240, 248, 255), hsl(208, 100%, 97%). Its relative luminance is 0.929, giving 1.07:1 against white and 19.58:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for aliceblue?

aliceblue is #F0F8FF, which is rgb(240, 248, 255) and hsl(208, 100%, 97%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is aliceblue light or dark?

Alice Blue has a relative luminance of 0.929 on a 0–1 scale, so it is a light color. Against white it scores 1.07:1; against black, 19.58:1.

Can I use aliceblue for text?

aliceblue reaches 19.58:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
