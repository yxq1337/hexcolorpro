#D2B48C — Tan

Tan is the CSS named color #D2B48C — rgb(210, 180, 140), hsl(34, 44%, 69%). Its relative luminance is 0.482, giving 1.97:1 against white and 10.65:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for tan?

tan is #D2B48C, which is rgb(210, 180, 140) and hsl(34, 44%, 69%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is tan light or dark?

Tan has a relative luminance of 0.482 on a 0–1 scale, so it is a dark color. Against white it scores 1.97:1; against black, 10.65:1.

Can I use tan for text?

tan reaches 10.65:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
