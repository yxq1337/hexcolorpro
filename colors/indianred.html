#CD5C5C — Indian Red

Indian Red is the CSS named color #CD5C5C — rgb(205, 92, 92), hsl(0, 53%, 58%). Its relative luminance is 0.214, giving 3.98:1 against white and 5.28:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for indianred?

indianred is #CD5C5C, which is rgb(205, 92, 92) and hsl(0, 53%, 58%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is indianred light or dark?

Indian Red has a relative luminance of 0.214 on a 0–1 scale, so it is a dark color. Against white it scores 3.98:1; against black, 5.28:1.

Can I use indianred for text?

indianred reaches 5.28:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
