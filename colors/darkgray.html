#A9A9A9 — Dark Gray

Dark Gray is the CSS named color #A9A9A9 — rgb(169, 169, 169), hsl(0, 0%, 66%). Its relative luminance is 0.397, giving 2.35:1 against white and 8.94:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for darkgray?

darkgray is #A9A9A9, which is rgb(169, 169, 169) and hsl(0, 0%, 66%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is darkgray light or dark?

Dark Gray has a relative luminance of 0.397 on a 0–1 scale, so it is a dark color. Against white it scores 2.35:1; against black, 8.94:1.

Can I use darkgray for text?

darkgray reaches 8.94:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
