#D2691E — Chocolate

Chocolate is the CSS named color #D2691E — rgb(210, 105, 30), hsl(25, 75%, 47%). Its relative luminance is 0.239, giving 3.63:1 against white and 5.78:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for chocolate?

chocolate is #D2691E, which is rgb(210, 105, 30) and hsl(25, 75%, 47%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is chocolate light or dark?

Chocolate has a relative luminance of 0.239 on a 0–1 scale, so it is a dark color. Against white it scores 3.63:1; against black, 5.78:1.

Can I use chocolate for text?

chocolate reaches 5.78:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
