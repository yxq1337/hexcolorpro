#A52A2A — Brown

Brown is the CSS named color #A52A2A — rgb(165, 42, 42), hsl(0, 59%, 41%). Its relative luminance is 0.098, giving 7.08:1 against white and 2.96:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for brown?

brown is #A52A2A, which is rgb(165, 42, 42) and hsl(0, 59%, 41%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is brown light or dark?

Brown has a relative luminance of 0.098 on a 0–1 scale, so it is a dark color. Against white it scores 7.08:1; against black, 2.96:1.

Can I use brown for text?

brown reaches 7.08:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
