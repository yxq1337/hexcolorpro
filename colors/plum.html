#DDA0DD — Plum

Plum is the CSS named color #DDA0DD — rgb(221, 160, 221), hsl(300, 47%, 75%). Its relative luminance is 0.457, giving 2.07:1 against white and 10.15:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for plum?

plum is #DDA0DD, which is rgb(221, 160, 221) and hsl(300, 47%, 75%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is plum light or dark?

Plum has a relative luminance of 0.457 on a 0–1 scale, so it is a dark color. Against white it scores 2.07:1; against black, 10.15:1.

Can I use plum for text?

plum reaches 10.15:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
