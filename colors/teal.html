#008080 — Teal

Teal is the CSS named color #008080 — rgb(0, 128, 128), hsl(180, 100%, 25%). Its relative luminance is 0.170, giving 4.77:1 against white and 4.40:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for teal?

teal is #008080, which is rgb(0, 128, 128) and hsl(180, 100%, 25%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is teal light or dark?

Teal has a relative luminance of 0.170 on a 0–1 scale, so it is a dark color. Against white it scores 4.77:1; against black, 4.40:1.

Can I use teal for text?

teal reaches 4.77:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
