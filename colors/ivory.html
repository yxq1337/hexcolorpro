#FFFFF0 — Ivory

Ivory is the CSS named color #FFFFF0 — rgb(255, 255, 240), hsl(60, 100%, 97%). Its relative luminance is 0.991, giving 1.01:1 against white and 20.81:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for ivory?

ivory is #FFFFF0, which is rgb(255, 255, 240) and hsl(60, 100%, 97%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is ivory light or dark?

Ivory has a relative luminance of 0.991 on a 0–1 scale, so it is a light color. Against white it scores 1.01:1; against black, 20.81:1.

Can I use ivory for text?

ivory reaches 20.81:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
