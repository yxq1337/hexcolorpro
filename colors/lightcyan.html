#E0FFFF — Light Cyan

Light Cyan is the CSS named color #E0FFFF — rgb(224, 255, 255), hsl(180, 100%, 94%). Its relative luminance is 0.946, giving 1.05:1 against white and 19.92:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for lightcyan?

lightcyan is #E0FFFF, which is rgb(224, 255, 255) and hsl(180, 100%, 94%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is lightcyan light or dark?

Light Cyan has a relative luminance of 0.946 on a 0–1 scale, so it is a light color. Against white it scores 1.05:1; against black, 19.92:1.

Can I use lightcyan for text?

lightcyan reaches 19.92:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
