#8FBC8F — Dark Sea Green

Dark Sea Green is the CSS named color #8FBC8F — rgb(143, 188, 143), hsl(120, 25%, 65%). Its relative luminance is 0.438, giving 2.15:1 against white and 9.76:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for darkseagreen?

darkseagreen is #8FBC8F, which is rgb(143, 188, 143) and hsl(120, 25%, 65%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is darkseagreen light or dark?

Dark Sea Green has a relative luminance of 0.438 on a 0–1 scale, so it is a dark color. Against white it scores 2.15:1; against black, 9.76:1.

Can I use darkseagreen for text?

darkseagreen reaches 9.76:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
