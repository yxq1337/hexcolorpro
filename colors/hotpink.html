#FF69B4 — Hot Pink

Hot Pink is the CSS named color #FF69B4 — rgb(255, 105, 180), hsl(330, 100%, 71%). Its relative luminance is 0.347, giving 2.65:1 against white and 7.93:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for hotpink?

hotpink is #FF69B4, which is rgb(255, 105, 180) and hsl(330, 100%, 71%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is hotpink light or dark?

Hot Pink has a relative luminance of 0.347 on a 0–1 scale, so it is a dark color. Against white it scores 2.65:1; against black, 7.93:1.

Can I use hotpink for text?

hotpink reaches 7.93:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
