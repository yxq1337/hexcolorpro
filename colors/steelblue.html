#4682B4 — Steel Blue

Steel Blue is the CSS named color #4682B4 — rgb(70, 130, 180), hsl(207, 44%, 49%). Its relative luminance is 0.206, giving 4.11:1 against white and 5.11:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for steelblue?

steelblue is #4682B4, which is rgb(70, 130, 180) and hsl(207, 44%, 49%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is steelblue light or dark?

Steel Blue has a relative luminance of 0.206 on a 0–1 scale, so it is a dark color. Against white it scores 4.11:1; against black, 5.11:1.

Can I use steelblue for text?

steelblue reaches 5.11:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
