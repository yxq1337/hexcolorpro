#FAEBD7 — Antique White

Antique White is the CSS named color #FAEBD7 — rgb(250, 235, 215), hsl(34, 78%, 91%). Its relative luminance is 0.846, giving 1.17:1 against white and 17.93:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for antiquewhite?

antiquewhite is #FAEBD7, which is rgb(250, 235, 215) and hsl(34, 78%, 91%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is antiquewhite light or dark?

Antique White has a relative luminance of 0.846 on a 0–1 scale, so it is a light color. Against white it scores 1.17:1; against black, 17.93:1.

Can I use antiquewhite for text?

antiquewhite reaches 17.93:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
