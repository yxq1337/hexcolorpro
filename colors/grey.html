#808080 — Grey

Grey is the CSS named color #808080 — rgb(128, 128, 128), hsl(0, 0%, 50%). Its relative luminance is 0.216, giving 3.95:1 against white and 5.32:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for grey?

grey is #808080, which is rgb(128, 128, 128) and hsl(0, 0%, 50%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is grey light or dark?

Grey has a relative luminance of 0.216 on a 0–1 scale, so it is a dark color. Against white it scores 3.95:1; against black, 5.32:1.

Can I use grey for text?

grey reaches 5.32:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
