#4B0082 — Indigo

Indigo is the CSS named color #4B0082 — rgb(75, 0, 130), hsl(275, 100%, 25%). Its relative luminance is 0.031, giving 12.95:1 against white and 1.62:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for indigo?

indigo is #4B0082, which is rgb(75, 0, 130) and hsl(275, 100%, 25%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is indigo light or dark?

Indigo has a relative luminance of 0.031 on a 0–1 scale, so it is a dark color. Against white it scores 12.95:1; against black, 1.62:1.

Can I use indigo for text?

indigo reaches 12.95:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
