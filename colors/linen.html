#FAF0E6 — Linen

Linen is the CSS named color #FAF0E6 — rgb(250, 240, 230), hsl(30, 67%, 94%). Its relative luminance is 0.884, giving 1.12:1 against white and 18.67:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for linen?

linen is #FAF0E6, which is rgb(250, 240, 230) and hsl(30, 67%, 94%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is linen light or dark?

Linen has a relative luminance of 0.884 on a 0–1 scale, so it is a light color. Against white it scores 1.12:1; against black, 18.67:1.

Can I use linen for text?

linen reaches 18.67:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
