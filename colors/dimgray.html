#696969 — Dim Gray

Dim Gray is the CSS named color #696969 — rgb(105, 105, 105), hsl(0, 0%, 41%). Its relative luminance is 0.141, giving 5.49:1 against white and 3.83:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for dimgray?

dimgray is #696969, which is rgb(105, 105, 105) and hsl(0, 0%, 41%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is dimgray light or dark?

Dim Gray has a relative luminance of 0.141 on a 0–1 scale, so it is a dark color. Against white it scores 5.49:1; against black, 3.83:1.

Can I use dimgray for text?

dimgray reaches 5.49:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
