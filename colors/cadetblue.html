#5F9EA0 — Cadet Blue

Cadet Blue is the CSS named color #5F9EA0 — rgb(95, 158, 160), hsl(182, 25%, 50%). Its relative luminance is 0.294, giving 3.05:1 against white and 6.88:1 against black, so it works as a text color on black.

What is the hex code for cadetblue?

Is cadetblue light or dark?

Can I use cadetblue for text?
