#20B2AA — Light Sea Green

Light Sea Green is the CSS named color #20B2AA — rgb(32, 178, 170), hsl(177, 70%, 41%). Its relative luminance is 0.351, giving 2.62:1 against white and 8.01:1 against black, so it works as a text color on black.

Frequently asked questions

What is the hex code for lightseagreen?

lightseagreen is #20B2AA, which is rgb(32, 178, 170) and hsl(177, 70%, 41%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is lightseagreen light or dark?

Light Sea Green has a relative luminance of 0.351 on a 0–1 scale, so it is a dark color. Against white it scores 2.62:1; against black, 8.01:1.

Can I use lightseagreen for text?

lightseagreen reaches 8.01:1 against black, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
