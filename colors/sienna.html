#A0522D — Sienna

Sienna is the CSS named color #A0522D — rgb(160, 82, 45), hsl(19, 56%, 40%). Its relative luminance is 0.137, giving 5.62:1 against white and 3.74:1 against black, so it works as a text color on white.

Frequently asked questions

What is the hex code for sienna?

sienna is #A0522D, which is rgb(160, 82, 45) and hsl(19, 56%, 40%). It is one of the 148 CSS named colors defined by the CSS Color Module Level 4.

Is sienna light or dark?

Sienna has a relative luminance of 0.137 on a 0–1 scale, so it is a dark color. Against white it scores 5.62:1; against black, 3.74:1.

Can I use sienna for text?

sienna reaches 5.62:1 against white, which clears WCAG 2.2 AA for normal text (4.5:1) at any size.
